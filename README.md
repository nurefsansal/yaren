
# Yâren ☕

Yâren, kahve kültüründen ve birlikte geçirilen güzel anlardan ilham alan, React ile geliştirilmiş örnek bir kahve markası web sitesidir.

## Özellikler

- Responsive tasarım
- Açılış animasyonu
- Türk kahvesi, espresso ve filtre kahve kartları
- İletişim formu ve alan doğrulaması
- Modern tipografi ve kahve temalı renk paleti

## Kullanılan teknolojiler

- React
- Vite
- JavaScript
- CSS

## Kurulum

```bash
npm install
npm run dev
```

Terminalde gösterilen yerel adresi tarayıcıda açın.

## Üretim derlemesi

```bash
npm run build
```

Not: İletişim formu demo amaçlıdır; bir sunucuya veri göndermez.
